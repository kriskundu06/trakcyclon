# TrakCyclon — CycloneTrack AI

An end-to-end machine-learning application for exploring historical tropical-cyclone tracks and generating experimental 6-, 12-, and 24-hour trajectory predictions for the **North Indian Ocean** (Bay of Bengal and Arabian Sea).

> **Research / educational project:** Model predictions are experimental and are not official meteorological forecasts, warnings, or a substitute for guidance from national weather agencies. The historical dataset is not a live cyclone-activity feed.

## Overview

TrakCyclon combines a React-based interface with a Python FastAPI backend and trained XGBoost models. Users can explore historical cyclone records, inspect regional dataset statistics, and request model-generated future positions at multiple forecast horizons.

## Key Features

- **Cyclone trajectory prediction:** Experimental 6-hour, 12-hour, and 24-hour predictions.
- **Historical cyclone explorer:** Browse historical cyclone tracks and records.
- **Interactive map:** View historical and predicted track positions.
- **Analytics dashboard:** Explore dataset coverage and regional statistics.
- **History search:** Search and filter historical cyclone records.
- **Model evaluation artifacts:** Includes selected prediction and error-analysis outputs.

## Model Evaluation

Current test-set results recorded for the XGBoost trajectory models:

| Forecast Horizon | Mean Track Error | Median Track Error | RMSE | 90th Percentile Error |
|---|---:|---:|---:|---:|
| 6 hours | 32.73 km | 27.37 km | 40.51 km | 60.55 km |
| 12 hours | 67.61 km | 57.09 km | 81.56 km | 126.48 km |
| 24 hours | 138.84 km | 119.52 km | 164.13 km | 256.44 km |

These metrics describe evaluation results on the test data; they do not guarantee future forecast accuracy.

## Dataset

The project uses historical North Indian Ocean cyclone observations based on IBTrACS-derived data.

- **57,874 observations**
- **1,860 unique cyclones**
- **Arabian Sea:** 15,426 observations across 618 cyclones
- **Bay of Bengal:** 42,448 observations across 1,591 cyclones
- **Recorded date range:** 1842-10-25 to 2026-10-28

The application uses `data/processed/cyclones_clean.csv`.

## Run Locally

### Prerequisites

- Python 3.10 or a compatible version
- Node.js and npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/kriskundu06/trakcyclon.git
cd trakcyclon
```

### 2. Set up the backend

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the backend dependencies, then run:

```bash
python -m uvicorn backend.main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.

### 3. Set up the frontend

Open a second terminal:

```bash
cd frontend
npm install
```

Create a `frontend/.env` file:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

Start the frontend:

```bash
npm run dev
```

Open the local URL printed by Vite.

## API Endpoints

| Endpoint | Purpose |
|---|---|
| `GET /` | API root / service information |
| `GET /health` | Backend health check |
| `GET /dataset-stats` | Dataset coverage and summary statistics |
| `POST /predict` | Generate cyclone trajectory predictions |
| `GET /history` | Retrieve historical cyclone records |
| `GET /history/filters` | Retrieve available history filter values |

For exact request and response schemas, inspect `backend/main.py`.

## Limitations and Responsible Use

- Predictions are generated by experimental machine-learning models and may be inaccurate, especially at longer forecast horizons.
- Historical records do not indicate current cyclone activity.
- This project is not an operational early-warning system.
- Always rely on official meteorological agencies for cyclone advisories, warnings, evacuation guidance, and safety decisions.
